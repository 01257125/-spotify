# 🎵 back number 名曲賞析 App (Spotify UI Edition)

這是一個使用 **SwiftUI** 開發的 macOS/iOS 音樂播放與賞析應用程式，以日本國民搖滾樂團 **back number** 為主題。本專案將基礎的狀態切換作業，深度升級為具備 `AVFoundation` 真實音訊串流與正統 Spotify 視覺風格的專業級播放器。

## ✨ 開發總結與核心技術

### 1. 核心規格與資料結構實作
* **資料模型 (Song)**：定義專屬結構體，完整封裝歌名、圖片名稱、深度賞析介紹、所屬專輯、發行年份、歌詞片段與音訊串流 URL。
* **精選曲目清單**：收錄 back number 4 首代表神曲（《高嶺の花子さん》、《水平線》、《クリスマスソング》、《ハッピーエンド》）。
* **狀態管理與互動邏輯**：
  * 使用 `@State private var currentIndex` 追蹤與控制當前播放曲目。
  * **無縫切換邏輯**：實作「上一首/下一首」按鈕，並在陣列邊界加入自動循環 (Loop) 機制。
  * **進階隨機播放**：透過 `while` 迴圈機制，確保隨機抽選出來的索引值必定不等於當前曲目，避免無效點擊。
  * **平滑轉場**：在切換歌曲時加入 `.animation(.easeInOut)` 提供滑順的視覺過渡動畫。

### 2. 官方高畫質封面自動匯入
* **資源管理**：自動從 back number 日本官方網站與 CDN 檢索並下載 4 首名曲的官方單曲封面圖檔。
* **動態索引**：在專案的 `Assets.xcassets` 中自動建立完整的目錄與 `Contents.json` 索引結構（包含 `takane`, `suiheisen`, `christmas`, `happyend`），確保高解析度圖檔精準渲染。

### 3. 真實音訊串流整合 (Audio Streaming)
* **AVFoundation 實作**：串接 Apple 音訊串流服務，透過 `AVPlayer` 實現 4 首名曲的官方試聽音樂播放，徹底解決「只有畫面沒聲音」的痛點。
* **網路權限配置**：為 macOS App target 自動配置 `com.apple.security.network.client` 網路通訊權限 (Entitlement)。
* **全方位播放控制**：點擊播放按鈕 (Play/Pause) 可即時播送歌曲；切換上一首/下一首/隨機時，系統會自動無縫切換音軌並接續播放。

### 4. 正統 Spotify 播放器 UI/UX 全面翻新
* **macOS 寬螢幕自適應雙欄佈局**：
  * **左側**：配置大尺寸唱片封面、歌名/專輯、愛心收藏鍵，以及 Spotify 經典控制按鈕列。
  * **右側**：實作 Spotify 標誌性的「即時滾動歌詞卡片 (Lyrics Card)」與「名曲賞析深度解說」，徹底解決視窗橫向拉寬時內容空洞的問題。
* **經典視覺設計系統**：
  * **色彩還原**：精準使用 Spotify 綠 (`#1DB954`) 與深黑底色 (`#121212`)。
  * **沉浸式光暈**：背景採用當前專輯封面提取色彩，並進行 65px 的即時高斯模糊 (`.blur`)，營造極具質感的沉浸式音樂氛圍。
